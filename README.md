# Boombapdap

Кроссплатформенное приложение для создания битов (Beatmaker App).

## Архитектура

Проект разделен на две основные части:

### 1. `rust_core/` (Ядро на Rust)
Отвечает за высокопроизводительную обработку данных и аудио-логику:
- **Генерация паттернов**: Алгоритмы создания ритмических рисунков.
- **Обработка сэмплов**: Низкоуровневая работа с аудио-данными.
- **BPM/Swing**: Точный тайминг и "кач".
- **Микшер и эффекты**: Обработка звука в реальном времени.
- **Экспорт**: Рендеринг финального проекта в аудио-файлы.

### 2. `app_flutter/` (Интерфейс на Flutter)
Обеспечивает отзывчивый и современный пользовательский интерфейс:
- **Piano Roll**: Визуальный редактор нот.
- **Step Sequencer UI**: Сетка для быстрого создания ритмов.
- **Библиотека сэмплов**: Удобная навигация по звукам.
- **Drag-and-drop**: Интуитивное управление элементами.
- **Настройки и пресеты**: Управление параметрами проекта.

## Разработка

Для работы с проектом потребуются:
- Flutter SDK
- Rust (Cargo)
- Flutter Rust Bridge (рекомендуется для связи UI и ядра)
